# Boda Business Notebook

This project contains a small Python notebook that models a boda boda business with trip tracking, fare calculations, vehicle status, and summary reporting.

## Included

- Notebook: `BODA_BODA.ipynb`
- Business logic for trip recording and summaries
- Fare estimation and rating support

## How to run

Open the notebook in Jupyter or VS Code and run all cells.

## Example

The notebook creates a `BodaBusiness` instance, records trips, and prints a detailed business summary.
